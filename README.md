## Introduction

Frappe Fusion Hrms provides the employee dashboard to create the check-in or checkout log from dashboard.


## Installation

### Manual Installation

1. [Install bench](https://github.com/frappe/bench).
2. [Install ERPNext](https://github.com/frappe/erpnext#installation).
3. [Install hrms](https://github.com/frappe/hrms#installation).
4. Once ERPNext and hrms are installed, add the Frappe Fusion Hrms app to your bench by running

	```sh
	$ bench get-app https://github.com/fusionsami/frappe-fusion-hrms.git
	```
5. After that, you can install the Frappe Fusion Hrms app on the required site by running
	```sh
	$ bench --site sitename install-app frappe_fusion_hrms
	```
